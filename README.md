# 🎓 사용자 맞춤형 시간표 추천 프로그램

> 사용자의 선호도와 수강 조건을 반영하여 개인에게 적합한 대학 시간표를 추천하는 프로그램

## 📌 프로젝트 소개

대학교에서 수강신청을 준비할 때 학생들은 개설된 강의 중에서 직접 강의를 비교하고
시간표를 구성해야 합니다.

하지만 단순히 수강 가능한 강의를 조합하는 것뿐만 아니라 **공강 여부, 선호 시간대,
등교 일수, 듣고 싶은 과목** 등 개인의 선호까지 고려하면 시간표를 구성하는 과정이
복잡해질 수 있습니다.

본 프로젝트는 사용자가 원하는 조건과 선호도를 입력하면 이를 바탕으로
**사용자에게 적합한 시간표를 자동으로 구성하고 추천하는 프로그램**을 개발하는 것을
목표로 합니다.

---

## 🎯 프로젝트 목표

본 프로젝트의 주요 목표는 다음과 같습니다.

1. 사용자가 수강하고 싶은 **강의 및 수강 조건**을 입력할 수 있도록 합니다.
2. 사용자의 **시간표 선호도**를 입력받습니다.
3. 시간이 겹치는 강의를 자동으로 확인합니다.
4. 입력된 조건을 만족하는 시간표 조합을 생성합니다.
5. 생성된 시간표 중 사용자의 선호도에 적합한 시간표를 추천합니다.

---

## 💡 사용자 선호 조건

사용자는 다음과 같은 조건을 설정할 수 있습니다.

- 선호하는 수업 시간대
- 원하는 공강 요일
- 최소/최대 수강 학점
- 듣고 싶은 강의
- 피하고 싶은 수업 시간
- 선호하는 등교 일수

예를 들어 다음과 같은 요청을 반영할 수 있습니다.

> "금요일에는 수업이 없었으면 좋겠어요."

> "오전 수업은 최대한 피하고 싶어요."

> "학교에 가는 날을 최소화하고 싶어요."

---

## ⚙️ 주요 기능

### 1. 강의 정보 입력

시간표 생성에 필요한 강의 정보를 입력받습니다.

- 과목명
- 교수명
- 수업 요일
- 수업 시간
- 학점

### 2. 사용자 선호도 입력

사용자가 원하는 시간표 조건을 입력받습니다.

### 3. 시간표 조합 생성

수업 시간이 서로 겹치지 않도록 가능한 시간표 조합을 생성합니다.

### 4. 맞춤형 시간표 추천

각 시간표가 사용자의 선호 조건을 얼마나 만족하는지 평가하여
적합한 시간표를 추천합니다.

---

## 🔄 프로그램 동작 과정

```text
강의 정보
    ↓
사용자 조건 및 선호도 입력
    ↓
수업 시간 충돌 검사
    ↓
가능한 시간표 조합 생성
    ↓
사용자 선호도 반영
    ↓
맞춤형 시간표 추천
'''
